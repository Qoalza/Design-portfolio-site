# Bibata Original Classic cursor assets

`bibata-original-classic-pointer.svg` and `bibata-original-classic-hand.svg` are
derived from the `original/left_ptr` and `hand/hand2` SVGs in
<https://github.com/ful1e5/Bibata_Cursor>. Their colour tokens were replaced
with Bibata Classic black (`#000000`) and white (`#FFFFFF`), then sized for the
web cursor hotspot. The upstream GPL-3.0 license is included as
`LICENSE-Bibata_Cursor.txt`.
