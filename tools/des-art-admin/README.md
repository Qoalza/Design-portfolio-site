# Des-art Admin

Локальная админка запускается приложением `dist/Des-art Admin.app`. Приложение не устанавливается автоматически и не добавляется в автозагрузку.

При первом запуске оно создаёт отдельную управляемую копию репозитория в `~/Library/Application Support/Des-art Admin/repository`, запускает UI только на `127.0.0.1:41731` и preview на `127.0.0.1:41732`. Повторный запуск открывает уже работающую админку.

Кнопка «Завершить работу админки» останавливает API/UI и принадлежащий приложению preview-процесс. До установки приложение остаётся проверочным артефактом внутри workspace.

Для установки после пользовательского подтверждения скопировать `Des-art Admin.app` в `/Applications`. До отдельного подтверждения этого делать нельзя.
