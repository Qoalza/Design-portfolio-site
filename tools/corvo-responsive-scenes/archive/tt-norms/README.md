# TT Norms Pro archive

Этот каталог сохраняет предыдущую реализацию Corvo на TT Norms Pro как
исторический reference. Он намеренно находится за пределами `site/`, поэтому
`serve.mjs` его не раздаёт и рабочие страницы его не импортируют.

- `source/` — HTML/CSS-снимок прежних четырёх сцен и shared font contract.
- `local-fonts/` — локальные лицензированные font-файлы; каталог игнорируется
  Git и не входит в пакет передачи.

Архив не является runnable-вариантом и не должен переноситься в Portfolio.
При необходимости вернуться к нему следует создавать отдельную задачу и
заново проверять права на шрифт.
