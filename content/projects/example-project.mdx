# Пример проектного кейса

Это тестовый материал для проверки свободного формата статьи. Здесь можно сочетать короткие описания, подробные наблюдения и разные типы контента без привязки к фиксированному шаблону.

## Контекст проекта

Проект посвящён рабочему инструменту для команд, которым важно видеть состояние задач и принимать решения на основе общей картины. **Текст и структура разделов могут меняться в зависимости от содержания конкретного кейса.**

### Наблюдения

- Пользователям нужен единый источник актуальной информации.
- Сложные сценарии важно раскрывать постепенно.
- Результаты решений должны быть понятны всей команде.

## Задача

В этом разделе можно описать исходную ситуацию, цели команды и вопросы, на которые требовалось ответить в ходе работы.

## Ограничения

Ограничения проекта могут быть связаны со сроками, существующими процессами, техническим контекстом или необходимостью поддержать несколько ролей пользователей.

1. Ограниченный срок на исследование.
2. Несколько групп пользователей.
3. Необходимость сохранить совместимость с текущим процессом.

## Процесс

Работа над проектом может включать исследование, формирование гипотез, проверку решений и постепенное уточнение сценариев.
