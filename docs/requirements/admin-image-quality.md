# Загрузка изображений в Admin: качество прежде веса

Статус: требование пользователя от 2026-10-04; обработчик Admin ещё не реализован. Реализация — отдельная Admin-линия, не Concept V2. Документ не разрешает перенос данных sandbox в canonical или production.

При загрузке тяжёлого PNG Admin должен предложить/применить проверенную оптимизацию в зависимости от назначения изображения. Приоритет: качество, затем вес. Определять контекст по слоту/назначению; при неизвестном назначении сохранять исходник и запрашивать контекст, не классифицировать молча.

- Экраны интерфейса, схемы, мелкий текст, тонкие линии: WebP lossless; сохранять исходные размеры, RGBA, прозрачность и корректное отображение цветового профиля. Запрещены автоматический resize, upscale, lossy и near-lossless. Проверять декодированный результат на совпадение пикселей/размеров; несовпадение останавливает замену.
- Фотографии: рассматривать AVIF/WebP/PNG и размеры отображения/плотность экрана отдельно. Существующая схема фото «Обо мне» не доказывает допустимость сжатия новой фотографии. Lossy/resize требуют установленной для этого контекста границы качества и проверки; без неё — lossless или исходник. Не выбирать формат по названию ОС; браузер выбирает поддерживаемый источник.
- Иллюстрации: учитывать градиенты, текст и альфа-канал. Если это чистый вектор, сохранять SVG; не растрировать автоматически. При неопределённости — исходник.
- Если кандидат не легче или качество не подтверждено, сохранить исходник. Не применять уменьшение ради заданного процента экономии.

Механика: сохранить оригинал → определить контекст → создать кандидат вне canonical → декодировать и проверить → сравнить вес → выбрать подтверждённый результат/исходник → показать исходный и итоговый формат, разрешение, вес, режим сжатия и причину выбора. При сбое оригинал доступен, publish не получает непроверенный кандидат. Повторная загрузка не должна повторно сжимать уже подготовленный файл.

До реализации уточнить точный upload/draft/compiler/preview/publish contract в актуальной Admin-линии. Не менять schema, ownership, source paths или provenance без предусмотренного gate. Это требование автоматического ingest, а не runtime-конверсия посетителю сайта.
