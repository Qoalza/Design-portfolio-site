# Проект

- Сайт-портфолио Product Designer.
- Основной язык интерфейса и контента — русский.
- Дизайн предоставляется отдельно в Figma.
- Не придумывать и не менять визуальные решения без прямого запроса.
- Основной контекст работ: сложные B2B, B2E, SaaS и внутренние системы.

# Технологии

- Next.js с App Router.
- TypeScript.
- npm.
- MDX для контента проектов.
- Без Tailwind CSS.
- Без сторонних UI-библиотек, базы данных, CMS и авторизации без отдельного согласования.

# Правила разработки

- Сначала изучать существующую структуру.
- Не менять файлы вне текущей задачи.
- Не проводить крупный рефакторинг без прямого запроса.
- Не добавлять зависимости без необходимости.
- Для новых зависимостей использовать конкретные стабильные версии.
- Сохранять строгую типизацию TypeScript.
- Не использовать any без необходимости.
- Не создавать декоративные заглушки и дизайн от себя.
- Учитывать адаптивность, доступность и производительность.

# Проверки

- Для текстовых и небольших конфигурационных изменений не запускать build без необходимости.
- Для изменений кода, маршрутов и зависимостей запускать npm run lint и npm run build.
- Не повторять уже успешно пройденные проверки без причины.

# Git

- Не работать напрямую в main.
- Для каждой задачи создавать отдельную ветку.
- Не выполнять merge без явного подтверждения пользователя.
- После завершения задачи самостоятельно:
  1. создать commit;
  2. выполнить push;
  3. создать Pull Request в main;
  4. показать краткий отчёт;
  5. запросить разрешение на merge.
- После разрешения:
  1. выполнить merge;
  2. переключиться на main;
  3. синхронизировать main с origin/main;
  4. показать git status и итоговый commit SHA.
