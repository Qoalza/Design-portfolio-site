## Правила SVG

- Экспортируется весь Figma component frame с исходным canvas и `viewBox`, а не отдельный внутренний vector/path.
- Внутренние отступы и визуальное положение геометрии сохраняются.
- `component.exportAsync` используется как основной штатный способ экспорта.
- Если штатный экспорт переводит `Line` или `Duotone` в outlined Fill, применяется graph-aware разбиение исходной vector network на настоящие SVG Stroke-пути. В baseline нет принятых outlined-версий `Line` или `Duotone`.
- Сохраняются stroke width, linecap, linejoin, transforms и opacity. `Light` использует `1 px`, `Medium` — `1.3 px`.
- Для управляемого цвета реконструированные Stroke-пути используют `currentColor`; исходный цвет `#E2E2EC` задан на корневом SVG как значение по умолчанию.
- `Line` и `Duotone` разделены на `Light` и `Medium`; семейства не смешиваются.
- `Color` и логотип сохраняют фиксированные исходные цвета.
- Визуальная оптимизация, обрезка canvas и уплотнение геометрии не выполняются.

## Mask

`Mask` — механизм использования и окрашивания, а не отдельное пользовательское семейство. Его два служебных компонента не экспортируются как иконки. В manifest у `line`, `duotone` и `solid` установлен `usesMask: true`; `color` сохраняет собственные цвета и не перекрашивается через Mask.

## Manifest и baseline

- `manifest.json` описывает локальные ID, Figma node ID, component key, классификацию, размеры, viewBox, пути и режим использования.
- `baseline.json` использует component key как основной стабильный ID и содержит структурный отпечаток, геометрический отпечаток и SHA-256 экспортированного SVG.
- Геометрический hash сохраняет визуально значимые различия. Нормализуются только служебные SVG ID экспортёра и межтеговые пробелы.

## Будущее обновление

`прочитать Figma → построить новый снимок → показать diff → получить подтверждение → заменить baseline и необходимые ассеты`

Обновление baseline само по себе не применяет изменения к сайту. Подключение или замена иконок в интерфейсе выполняется отдельной задачей после явного подтверждения.

## Результат экспорта и известное исходное состояние

Штатный Figma SVG exporter сериализовал strokes 26 сложных vector-network компонентов как fill-контуры. Эти 26 результатов отклонены и заменены подтверждённым graph-aware fallback: каждый итоговый путь содержит настоящий `stroke`, корректный `stroke-width`, `linecap`, `linejoin`, исходный transform и полный component `viewBox`. В `manifest.json` они отмечены как `exported-with-stroke-fallback`; неразрешённых outlined Stroke-ассетов — `0`.

Повторная read-only проверка актуальной Figma подтвердила, что `Medium / Arrows / Refresh-point` теперь использует `1.3 px`. У `Line / Light / Sale-02` видимый слой и экспорт используют `1 px`; в источнике остаётся скрытый legacy-слой `1.3 px`, который не попадает в SVG и не влияет на baseline.

Перед будущей заменой baseline нужно повторить структурную проверку всех SVG и отдельно отклонить любой `Line`/`Duotone`, где основной рисунок снова оказался outlined Fill.
